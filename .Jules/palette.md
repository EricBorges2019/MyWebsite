# Palette's Journal - Eric Borges Website

## 2025-05-14 - Foundational HTML Cleanup for Accessibility
**Learning:** Legacy static sites often harbor significant "structural rot" (mismatched tags, invalid nesting) that blocks accessibility. Consolidation of malformed head/body tags and refactoring into cohesive, high-tap-target anchor tags significantly improves both screen reader performance and touch usability.
**Action:** Always verify HTML tag balance and nesting before adding ARIA labels, as structural errors can negate accessibility improvements.
